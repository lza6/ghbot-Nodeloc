ghbot v2.0 迭代报告

ghbot 是基于 GitHub Actions 的机器人，用 goose CLI（OpenAI 兼容 chat API）完成 PR 审查、Issue/PR 分类、@bot 对话、冲突修复，并可选运行只读 webhook 长驻模式。 本次 v2.0 半程迭代按《下一步改进指南》M0–M7 推进，第一阶段落地 M0 测试加固、M1 可靠性、M2 可观测性三个方向，全部门禁通过、无 P0 阻塞项。

CTX

项目与本次迭代范围

处理不受信任的 PR 内容与多种凭据，凭据隔离是硬性红线：GitHub token、App 私钥、R2 与真实 goose API key 绝不进入 goose 容器、PR 快照或 git 子进程环境。

系统能力地图

ghbot 在生产中同时承担五个链路，本次迭代未改变其对外行为，仅加固内部质量。

1 PR 审查 review / change / comment / result 2 Issue/PR 分类 标签 + 两阶段重复检测 3 @bot 对话 一次性 Docker 容器 + 脱敏快照 4 冲突修复 safeToCommit=true 后才推送 5 Webhook 模式 可选 · 默认关闭 · 只读

合并策略由 REVIEW_POLICY 控制（默认 allow），AUTO_MERGE 保持 opt-in； 事件路由在 v1.2.0 已提取为 src/actions/router.ts 的 EventRouter，review / triage / chat / conflict 四类流程在此分发。
